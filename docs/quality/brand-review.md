# Brand review rubric

Product reviews every brand deliverable against this before it reaches the founder or
another session. Score each line 0–2. Anything scoring 0 goes back with notes; a direction
needs 18/24 or better to be shown to the founder.

## Strategy fit
1. Expresses "a local friend texting", not a resort, airline or tourism board
2. Unmistakably Mauritian to someone who has been there; not generic tropical
3. Consistent with the voice and tone guide (checked against `design/copy.md` once it exists)

## Craft
4. Wordmark reads correctly at 48 px and in mono; no detail that disappears at icon size
5. Symbol, if any, is drawn from the island and is not a dodo, palm, pin or wave cliché
6. Palette: five core colours plus neutrals, every text pairing documented and passing WCAG AA
7. Type: licence confirmed for web embedding and print, cost stated
8. Stamp system: rules are specific enough that a second illustrator could draw stamp 7 and
   it would match stamps 1, 2 and 11

## Usability
9. Survives outdoor sunlight on a phone (contrast, no thin light-on-light)
10. Print applications are press-ready: bleed, CMYK or stated conversion, real dimensions
11. Developer-usable: tokens in JSON with names interface design can adopt without renaming

## Hygiene
12. Nothing lifted from an existing brand; sources for inspiration listed; no AI-generated
    imagery passed off as final artwork without saying so

## Process
- Brand submits a milestone as a pull request plus a report. Product scores it here, writes
  the scores and notes into the PR, and either requests changes or approves.
- Only Product shows brand work to the founder, with the scores attached, so the founder
  sees a vetted shortlist rather than everything produced.
- Founder feedback comes back through Product, translated into specific revisions, not
  forwarded raw.
